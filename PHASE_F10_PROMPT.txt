# PHASE F10 IMPLEMENTATION PROMPT

Kamu adalah AI code generator untuk sistem SIMPRESMA (Laravel 11 + React 18 TypeScript).

## TASK OVERVIEW
Implementasikan 2 fitur baru di Phase F10:
1. Data Export Engine (Excel/CSV) untuk Wadek dan Tendik
2. Telegram Bot Notification untuk update status pengajuan

## TECH STACK
- Backend: Laravel 11, Sanctum, Events/Listeners
- Frontend: React 18, TypeScript 5, Vite 5, Shadcn/ui, Zustand
- Package: maatwebsite/excel v3.1

## REQUIREMENT SUMMARY

### Feature 1: Export Excel/CSV
- **Endpoint**: GET /api/wadek/export, GET /api/tendik/export
- **Format**: .xlsx (default), .csv
- **Filter**: ?prodi=SI&status=diterima&format=xlsx
- **Kolom (17)**: No, NIM, Nama Mahasiswa, Program Studi, Nama Lomba, Bidang Lomba, Tingkatan, Tahapan/Capaian, Tanggal Pengajuan, Status, SKS Dikonversi, Mata Kuliah, Nilai Akhir, Link Sertifikat, Link SK, Verifikator, Tanggal Verifikasi
- **Akses**:
  - Wadek: Semua data
  - Tendik: Hanya status "diterima" dan "selesai"
- **Frontend**: Component <ExportButton> dengan dropdown Excel/CSV

### Feature 2: Telegram Notification
- **Trigger Notifikasi**:
  - Ke Mahasiswa: status → "diterima", "ditolak", "selesai"
  - Ke Verifikator: pengajuan baru "pending" dari prodi binaannya
  - Ke Tendik: pengajuan baru "diterima"
- **Setup**:
  - Migration: tambah kolom `telegram_chat_id` di tabel `users`
  - Service: TelegramService dengan method sendMessage()
  - Event: PengajuanStatusChanged
  - Listener: SendTelegramNotification
- **Webhook**: POST /api/telegram/webhook (handle command /start untuk dapatkan chat_id)
- **Frontend**: Component <TelegramConnect> di halaman Profil dengan flow:
  1. User buka bot @simpresma_unej_bot, kirim /start
  2. Bot balas dengan Chat ID
  3. User copy-paste Chat ID ke form
  4. POST /api/auth/connect-telegram
  5. Tampilkan status "Terhubung" dengan tombol disconnect

## IMPLEMENTATION NOTES

1. **Export Class**: Gunakan FromCollection + WithHeadings + WithMapping dari maatwebsite/excel
2. **Download Response**: Set header Content-Disposition untuk trigger browser download
3. **Telegram API**: Direct HTTP POST ke https://api.telegram.org/bot{TOKEN}/sendMessage
4. **Event Dispatch**: Gunakan event(new PengajuanStatusChanged(...)) setelah update status
5. **Error Handling**: Jika Telegram API gagal, log error tapi jangan block proses utama
6. **Frontend API Call**: Gunakan fetch() dengan responseType blob untuk download file
